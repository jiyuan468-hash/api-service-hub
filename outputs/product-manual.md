## 3. 数据处理 API

### 一句话介绍
**"PDF/Excel/Word 一键互转，告别手动排版和格式转换烦恼"**

### 核心功能
1. **PDF → 文本**：提取结构化文本，保留分页标记
2. **Excel → CSV**：自动处理多 Sheet，批量导出
3. **Word → Markdown**：智能解析标题层级和表格
4. **文件验证**：自动校验类型和大小（最大 20MB）
5. **Job ID 追踪**：每次转换都有唯一编号，方便审计

### 技术规格
- 框架：FastAPI
- 依赖库：pdfplumber, pandas, python-docx, openpyxl
- 最大文件大小：20MB/文件
- 部署方式：Docker / VPS

### 推荐客户场景

| 内容管理 | Word 转 Markdown 发布到 CMS | 无缝接入工作流 |
| 档案管理 | 历史文档数字化处理 | 标准化存储 |

## 4. 爬虫服务

### 一句话介绍
**"定时采集目标网站数据，结构化输出，竞品动态一目了然"**

### 核心功能
1. **单页抓取**：一键获取网页标题、正文、链接
2. **字段自定义**：按需提取特定内容
3. **反反爬机制**：随机 User-Agent + 请求间隔 + 自动重试
4. **任务持久化**：所有结果存 SQLite，随时查询
5. **Job ID 追踪**：每个抓取任务可查可追溯

## 6. 客户常见问题 FAQ

**Q: 部署需要我自己准备服务器吗？**
A: 可以部署到你的云服务器（阿里云/腾讯云），也可以使用我们的免费 tier（Render/Railway）。首次部署免费指导。

**Q: API 调用有延迟吗？**
A: AI Chat API 平均响应时间 500ms-2s（取决于模型），其他服务在 100ms 以内。

**Q: 数据安全怎么保证？**
A: 所有数据传输使用 HTTPS，API Key 认证，无用户数据存储。爬虫和数据处理均在服务端完成。

**Q: 可以定制开发吗？**
A: 可以！所有源码均可二次开发。定制需求单独报价，通常 3-7 天交付。

**Q: 如果服务挂了怎么办？**
A: 我们的服务提供 99.9% 可用性保障。如出现异常，承诺 2 小时内响应处理。
